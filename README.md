## Problem Description

A PV panel delivers maximum power at a single operating point (MPP) that moves with irradiance, temperature, and load.
A DC–DC boost converter changes its duty cycle *D* so the panel stays at that point.
Conventional MPPT methods (P&O, InC) use a fixed step size. This forces a trade-off between tracking speed and steady-state oscillation.
A fuzzy controller instead picks an adaptive step size Δ*D* based on how far the panel is from the MPP.

## Method

The paper compares four hybrid fuzzy MPPT controllers. All four use Mamdani inference with centroid defuzzification, and all output Δ*D*.

| ID | Inputs | Rule base |
|---|---|---|
| Alg. 1 (P&O-FLC) | P–V slope *E* = ΔP/ΔV, power change ΔP | 7×7 |
| Alg. 2 (P&O-FLC) | *E*, change of slope *CE* | 7×7 |
| Alg. 3 (InC-FLC) | SInC = I/V + dI/dV | 1×7 |
| **Proposed** (InC-FLC) | SInC, CSI = ΔSInC | 5×7 |

At the MPP, SInC = 0. SInC < 0 means the operating point is right of the MPP, so *D* is increased. SInC > 0 means it is left of the MPP, so *D* is decreased.

## Fuzzy System Architecture

```
 V_pv, I_pv ──► compute SInC, CSI ──► fuzzify ──► Mamdani rule base (5×7) ──► centroid ──► ΔD
                                                                                       │
                                                              D[k] = D[k-1] + ΔD ◄─────┘ ──► boost converter
```

## Dataset

No external dataset is used. All inputs are synthetic simulation scenarios, generated by `src/scenarios.py`:

- SunPower SPR-210 panel parameters (paper, Table 1) at 25 °C
- Step irradiance profile between 200 and 1000 W/m², changing every 0.2 s
- Step changes in load resistance
